## 👨‍💻 Sobre mim

Sou estudante de Engenharia de Software (4º período) e já tenho a rotina de quem trabalha com sistema no ar: hoje atuo como estagiário de informática dando suporte a sistemas de PDV/ERP, e isso significa lidar com venda que não bate, estoque inconsistente, nota fiscal e balcão parado esperando solução.

No meio disso, aprendi a ler banco de dados, escrever SQL para investigar o problema e corrigir na raiz. Foi essa vivência que me puxou para o desenvolvimento: construo meus próprios projetos full-stack (um PDV com Node.js, TypeScript, React e PostgreSQL) e uso IA como apoio para desenvolver e depurar, sempre entendendo o que está sendo feito.

Estou construindo experiência na prática e procuro um estágio em tecnologia para crescer ainda mais nessa direção.

```js
while (alive) {
  learn();
  build();
  debug();   // geralmente aqui passa mais tempo
  repeat();
}
```
